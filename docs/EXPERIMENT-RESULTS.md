# 完整实验成绩单

6 种后训练方法、9 轮实验，每种方法都有根因分析。

## 总览

| 方法 | dev | test | 判定 |
|---|---|---|---|
| Base greedy | 50% | 60% | 起点 |
| SFT（教师蒸馏） | 60% | **65%** | ✅ 部署 |
| DPO R1（SFT ref，统一 β=0.1） | 55% | — | ❌ σ→0 梯度趋零 |
| DPO R2（SFT ref，自适应 β） | 55% | — | ❌ β 非根因 |
| DPO R3（Base ref） | 50% | — | ❌ 学会排序但执行退化 |
| **RFT R1（自我改进）** | **70%** | **65%** | ✅ **最优可部署** |
| RFT R2（迭代） | 80% | 55% | ❌ 过拟合边界 |
| Hybrid（教师+RFT 混合训练） | — | 65% | 无突破 |
| Best-of-N 推理（4 samples） | — | 65% | 无突破 |

## SFT 详细结果

### 配置

| 项 | 值 |
|---|---|
| 基座 | Qwen2.5-Coder-7B-Instruct |
| 训练 | QLoRA NF4 双量化、r16/α32、lr 2e-5、3 epoch、78 步、峰值 10.3GB |
| 数据 | 教师 API；train 64 题 202 条去重样本（重放验证全过）；候选迁移省 56% |
| 质量 | 变异测试审计（104 题中 75 题零幸存变异体） |
| 选择 | 每 epoch 快照，dev 执行 pass@1 选型（Base 参与对照） |

### 单 seed（42）

| 集合 | Base | SFT | 变化 | 改善/退化 |
|---|---|---|---|---|
| dev | 10/20 (50%) | 12/20 (60%) | +10.0 pp | +3 / −1 |
| test | 12/20 (60%) | 13/20 (65%) | +5.0 pp | +1 / 0 |

### 3-seed 复现

| seed | dev 决策 | test | Δ (pp) |
|---|---|---|---|
| 42 | epoch-3 部署 | 65% | +5.0 |
| 43 | **保留 Base**（dev 无增益） | 60% | 0 |
| 44 | epoch-2 部署 | 60% | 0 |

均值 +1.7pp ± 2.4，CI [0, +5]，零退化。

## DPO 详细结果（三轮负结果）

| 轮次 | reference | β | 训练动态 | dev | 根因 |
|---|---|---|---|---|---|
| 1 | SFT adapter | 0.1 统一 | acc=1.0 全程，margin≈0 | 55% | SFT 对教师答案概率天然高于自身失败 → σ→0 |
| 2 | SFT adapter | 0.1/0.01 自适应 | 同上 | 55% | β 不是根因；结构性问题 |
| 3 | Base 模型 | 0.1/0.01 | loss 0.72→0.63，acc 混合，有真实梯度 | 50% | 学会了偏好排序，但排序≠执行能力 |

**方法论结论**：偏好排序优化不等同于执行能力提升。有效的偏好对需要 hard negatives
（策略更偏爱的失败），而非"教师答案 vs 模型自身失败"。

## RFT 详细结果

### 第 1 轮

| 项 | 值 |
|---|---|
| 起点 | SFT adapter（dev 60%） |
| 数据 | 模型自身采样 8 次/题 → 三层判分 → strict_pass 保留 + FailForge 恢复 |
| 样本量 | ~150 条 / ~50 题覆盖 |
| 训练 | 在 SFT adapter 基础上继续 QLoRA（lr 1e-5，2 epoch） |
| dev | **70%** (+10pp) |
| test | **65%**（维持） |

### 第 2 轮

| 项 | 值 |
|---|---|
| 起点 | RFT-R1 adapter（dev 70%） |
| 数据 | 同上（通过率提升至 ~78%） |
| 样本量 | 180 条 / 58 题覆盖 |
| 训练 | lr 5e-6（减半），2 epoch |
| dev | **80%** (+10pp) |
| test | **55%** (−10pp) ← 过拟合 |

**方法论结论**：RFT 第 1 轮同分布自我强化最有效；第 2 轮起输出分布过度收窄，
dev 继续上升但 test 退化。迭代自我改进有边界。

## Hybrid 与 Best-of-N

| 方法 | 改动 | test | 结论 |
|---|---|---|---|
| Hybrid | 教师 202 条 + RFT 150 条混合训练 | 65% | 无突破 |
| Best-of-N | greedy 先试→过公开测试返回→采样 4 次→选最优 | 65% | 无突破（模型对失败任务根本生成不出正确答案） |

## 失败任务分析（test 上 7 个始终未通过的任务）

涉及来源组整体落在 test（组级隔离下训练未见该家族），SFT/RFT/Hybrid/Best-of-N
均未修复。部分通过 FailForge 恢复了 2-3 题的训练数据，但 test 端仍未突破。

## 方法论发现汇总

1. **教师蒸馏有分布偏移天花板**（65%）
2. **DPO 三种失败模式各有根因**（σ→0 / β≠根因 / 排序≠执行）
3. **RFT 同分布自我强化最有效**（Round 1 +10pp dev）
4. **迭代自我改进有边界**（Round 2 起 test 退化）
5. **dev/test 来源组隔离 + 执行选型是关键防线**（三次实证拦截退化）
