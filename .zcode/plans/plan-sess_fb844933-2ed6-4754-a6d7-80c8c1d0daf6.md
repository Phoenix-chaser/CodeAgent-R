## Context

基于 FEST 论文（arxiv 2605.15012）的分析，CodeAgent-R 的 v7 DPO 实验失败根因是"教师答案 vs 模型自身失败"的偏好对在初始就已被正确排序（σ→0，梯度趋零）。FEST 提出的自适应 β 和 hard-negative 选择可直接解决此问题。

## 实施内容

### 1. 将分析写入文档

新建 `docs/FEST-ANALYSIS.md`，包含：论文核心思想、与 v7 DPO 的逐条对照、失败根因的理论解释、三个改进方案（自适应 β / hard-negative / 衰减权重）及优先级。

### 2. 改进 generate_preferences.py（Hard-Negative + 群组统计）

- 每题采样 N 次后记录群组统计（`group_solvable`, `group_pass_rate`）
- 选择 hard-negative：AST 指纹聚类中最常见的失败模式（模型最自信的错误）
- 将群组统计写入偏好对的 provenance

关键改动：
- `scripts/generate_preferences.py`：采样循环中收集全部 N 个结果（不只是取第一个失败）；加入 AST 指纹聚类逻辑选 hard-negative；provenance 新增 `group_solvable`、`group_pass_rate`、`rejected_fingerprint_count`

### 3. 改进 hf_dpo.py（自适应 β）

- DPODataset 读取偏好对中的 `group_solvable` 字段
- 训练循环中根据群组状态计算 per-pair β：
  - 不可解任务（group_solvable=False）→ β₁（默认 0.1）
  - 可解但本次失败 → β₂（默认 0.01）
- DPO collator 传递 group_solvable 标记
- train_dpo.py 新增 `--beta-unsolvable` / `--beta-solvable` 参数

关键改动：
- `src/agentlab/training/hf_dpo.py`：DPODataset 读 group_solvable；DPOCollator 传递标记；train_dpo 中 per-pair β 计算
- `scripts/train_dpo.py`：新增 CLI 参数

### 4. 更新测试

- `tests/test_hf_dpo.py`：新增自适应 β 的测试用例（group_solvable=True/False 产生不同 β）

### 5. 更新 README

- 能力表中 DPO 行简短提及"自适应 β"
